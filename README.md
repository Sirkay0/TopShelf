# TopShelf

An e-commerce website built with Next.js and TypeScript.

**Live demo:** (https://topshelf-weed.netlify.app/)

## Features
- Category pages with a carousel
- Product pages
- Customer testimonials section

## Tech stack
Next.js, TypeScript, [Tailwind CSS: confirm]

I built All the part, such as the category carousel, product page, and testimonials].
